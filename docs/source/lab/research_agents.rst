Research Agents
===============

A **research agent** writes a report. A **trading agent** (everything else in
the Lab) decides what to buy and sell. The two are different products:

.. list-table::
   :header-rows: 1
   :widths: 24 38 38

   * -
     - Trading agent
     - Research agent
   * - **You give it**
     - A strategy or prompt, and a backtest window.
     - A short form (a "mandate"): for example a target company or screening
       criteria.
   * - **You get**
     - Decisions, an equity curve, and backtest results.
     - A written analyst report you can read online and download.
   * - **Money and ranking**
     - Backtests use a simulated portfolio.
     - No portfolio, no backtest, and no leaderboard.

Research agents run on an outside service built by the agent's author, not on
the Lab's own models. The Lab lists them, collects your form, shows progress,
and stores the finished report for you.

.. note::

   A research report is generated by an AI system and is not investment,
   legal, or financial advice. Check the sources it cites before relying on it.


Two agents are available today:

- **Shell Company Screening Agent** — screens public shell companies as
  candidates for reverse mergers and takeovers.
- **Due Diligence Agent** — a public-information due diligence report on a
  target company.

Both are by Lin-Feihan; each card links to the author's GitHub repository.


Add a research agent
--------------------

You need an :doc:`ATL account <accounts>`. Browsing is open to everyone, but
adding a research agent and starting runs require you to be signed in.

1. Open **Community** and find the **Research Agents** shelf.
2. Each card shows the description, a rough run time (about 5 minutes), and
   the report formats the agent produces.
3. Click **Add to My Agents**. The button changes to **Added ✓**.

The agent now appears on the **Research Agents** shelf of **My Agents**. Adding
costs nothing and does not allocate any capital. **Remove** on the card takes
it off your shelf; you can add it again later.


Start a research run
--------------------

1. In **My Agents**, click **Open workbench** on the agent's card.
2. Under **New research run**, fill in the form. Required fields are marked;
   optional ones are folded under **Advanced options**.
3. Leave **Email me when the report is ready** ticked if you want a message
   (see below), then click **Start research**.

A run usually takes a few minutes. The **Runs** list beside the form shows each
run's status and when it was created; click a finished run to open its report.
A run that the service cannot complete is marked failed. Right after you start
a run, the note under the form shows the reason while the workbench stays open.

Research runs are paid for with :doc:`ATL Credits <credits_billing>`. When you
start a run, an amount is held from your balance; if your balance cannot cover
it, the run is refused and nothing is started. A run that fails releases its
hold.


The "report ready" email
------------------------

With **Email me when the report is ready** ticked, the Lab sends a short
message titled *[ATL] Your research report is ready* followed by the agent's
name, with a link back to the app. The report and its downloads are in the
workbench under **Runs**; open the workbench from the agent on My Agents.
Delivery depends on the deployment having email configured, so treat the message as a
convenience: the finished report is always in the workbench under **Runs**,
whether or not an email arrives.

The run keeps going if you close the page, so you do not need to wait on it.


Read and download the report
----------------------------

A finished report is shown on the page under **Report**. Download buttons
appear for the formats available for that run:

- **Markdown** — the report as plain text.
- **Word** — a ``.docx`` file (offered when the agent produced one).
- **PDF** — if the agent did not supply a PDF, the Lab builds one from the
  Markdown report.
- **Evidence JSON** — the sources and evidence behind the report, as data.

The agent's card lists which formats it produces, so the set differs a little by
agent. For example, the Shell Company Screening Agent offers Word and the Due
Diligence Agent does not. Reports are private to the account that started the
run.
